PixelFun 2
==========

Author: AINOLA

Notes:
Description:
Low-poly old-school with a sharp edge.

Wanna see more previews of the themes? See https://git.sr.ht/~ainola/pixelfun2/tree/master/item/previews/README.md

This cursor theme was created by zealkane (https://www.deviantart.com/zealkane) and the original files are hosted on DeviantArt (https://www.deviantart.com/zealkane/art/PixelFun-2-165038800).

These cursors were never designed for actual use but were instead the artist's mockup. The original files supplied by the artist are 20x20 pixel raster images. I've converted these .png files into .svg files.

This theme also provides some color alternatives:

breeze: Inspired by Plasma's default cursor theme
chocolate: A chocolate-chip cookie in your (virtual) hands
dracula: Inspired by the popular colorscheme of the same name
honey: Ooey-gooey warm yellows/browns
hotdogstand: Show off just how gaudy your desktop can be with sensual mustard and ketchup colors!
monochrome: Hi-contrast blacks and whites
synthwave: I'm pretty sure that these colors are required by law at this point
See all the theme previews at https://git.sr.ht/~ainola/pixelfun2/tree/master/item/previews/README.md

The project is hosted at https://git.sr.ht/~ainola/pixelfun2. Report issues on the accompanying todo tracker: https://todo.sr.ht/~ainola/pixelfun2.

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'PixelFun 2' from the Scheme dropdown
